      No price list. Here is what changes the number.
      
    
      A brochure site and a portal with logins and roles are not the same job, so one price table cannot be honest about both. Four things move the number.
      
    
        
      
      1. Number of screens
        A landing page is one layout. A site with a menu, a portal and a dashboard is a dozen, each with its own mobile behaviour.
        2. 
      
      2. Whether there is a backend
        A static site is content. The moment you need logins, a database, roles or an admin panel, it becomes software and is priced as software.
        3. 
      
      3. Who writes the content
        Copy, photos and product data ready? The build is quicker. If we write and source them, that is real work and it is quoted.
        4. 
      
      4. What happens after launch
        A one-off handover and an ongoing arrangement with SEO, ads and monthly changes are two different relationships. Both are fine; they are not the same price.
